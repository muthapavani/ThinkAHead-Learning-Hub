# ThinkAHead Course Catalog & Admin Guide

## Course release rule

- Registration: Courses 1 and 2 are free and are enrolled immediately.
- Monthly subscription: unlocks the next 2 paid courses for the active subscription month.
- Paid release month is controlled by `monthUnlock` in the Admin → Courses screen.
- Course images are controlled by the `thumbnail` field. Paste a hosted image URL or use an image path available in `public/assets/images/`.

## How to add a course from Admin Dashboard

1. Open **Admin Dashboard → Courses**.
2. Click **Add New Course**.
3. Enter the course name and short description.
4. Add a **Course Image URL**. The dashboard, My Learning and All Courses cards use this image.
5. Add a Banner Image URL if you want a separate hero image inside the course player.
6. Select the category and set the **Paid Release Month**. Month 1 means the first paid pair; Month 2 means the second paid pair, and so on.
7. Tick **Free course** only when the course should be available as part of the initial free pair.
8. Click **Create Course**. Existing courses can be opened with **Edit Course**.
